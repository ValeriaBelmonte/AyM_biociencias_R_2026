1 Propósito

En esta práctica trabajaremos con un registro de condiciones de cultivo de lechuga. El objetivo es importar la base, reconocer su estructura, corregir los nombres de las variables, detectar y completar un valor faltante y crear dos bases preparadas para los análisis posteriores.

2 Organización de las carpetas

Dentro de su proyecto de RStudio deberán contar con las siguientes carpetas:

  • datos originales: aquí se encuentra el archivo lechuga.xlsx.
  • datos transformados: aquí guardarán las nuevas bases producidas en esta práctica.

3 Reconocimiento de la base

Antes de importar el archivo, respondan:

  1. ¿Qué tipo de archivo es lechuga.xlsx?
  2. ¿En qué hoja se encuentran los datos?
  3. ¿Qué representa cada fila de la base: una planta o una medición de una planta en una fecha?
  4. ¿Por qué esta base puede considerarse una base longitudinal o de medidas repetidas?

Pista: cada planta aparece en más de una fila, porque fue medida en distintas fechas.

4 Cargar paquetes e importar la base

Instalen los paquetes solo si aún no los tienen instalados.

install.packages("tidyverse")
install.packages("readxl")
install.packages("janitor")

En cada sesión, carguen los paquetes:

library(tidyverse)
library(readxl)
library(janitor)

Limpiar entorno de trabajo

rm(list=ls())

Importen la hoja lechuga y guárdenla en un objeto llamado lechuga.

lechuga <- read_excel(
  "../datos originales/lechuga.xlsx",
  sheet = "lechuga"
)

6 Limpiar los nombres de las variables

Los nombres originales contienen mayúsculas, espacios, paréntesis y símbolos de unidad. Para facilitar el trabajo en R, se los normalizará.

#usar la función  clean_names() del paquete janitor
lechuga <- lechuga |> clean_names()
names(lechuga)

Verifique los nuevos nombres. Deberían quedar de la siguiente manera:

plant_id
date
temperature_c
humidity_porc
tds_value_ppm
ph_level
growth_days

7 Crear una fecha con formato uniforme

En esta planilla la fecha puede aparecer con formatos distintos.

  1. Crearemos una nueva variable llamada fecha, expresada como fecha de R.
lechuga <- lechuga |>
  mutate(
    fecha = coalesce(
      as.Date(date, format = "%Y-%m-%d"),
      as.Date(date, format = "%m/%d/%Y")
    )
  ) |>
  select(-date)

5.2 Compruebe que la nueva variable fue creada correctamente:

glimpse(lechuga)
range(lechuga$fecha)
  1. ¿Qué operación realizó select(-date)?

8 Detectar y completar el dato faltante

La base que recibieron contiene un dato faltante en la humedad de la planta 1, correspondiente al 25 de agosto de 2023. El valor correcto de humedad es 52.

Primero, identifiquen la cantidad de datos faltantes y observen la fila que los contiene.

sum(is.na(lechuga))

lechuga |>
  filter(is.na(humidity_porc))

Luego reemplacen únicamente ese valor faltante:

lechuga <- lechuga |>
  mutate(
    humidity_porc = case_when(
      plant_id == 1 &
        fecha == as.Date("2023-08-25") &
        is.na(humidity_porc) ~ 52,
      TRUE ~ humidity_porc
    )
  )

Verifiquen que no queden datos faltantes y que el valor se haya incorporado en la fila correcta.

sum(is.na(lechuga))

lechuga |>
  filter(plant_id == 1, fecha == as.Date("2023-08-25"))

11 Crear una base con todas las plantas en la primera fecha

Primero identifiquen la primera fecha cronológica y guárdenla en un objeto.

primera_fecha <- min(lechuga$fecha, na.rm = TRUE)
primera_fecha

Luego creen una nueva base que contenga todas las plantas medidas en esa fecha.

lechuga_primera_fecha <- lechuga |>
  filter(fecha == primera_fecha)

lechuga_primera_fecha

Comprueben cuántas filas tiene la nueva base y guárdenla dentro de datos transformados.

nrow(lechuga_primera_fecha)

write_csv(
  lechuga_primera_fecha,
  "../datos transformados/lechuga_primera_fecha.csv"
)
