Práctica para estudiantes 2

1 Propósito

En esta práctica trabajaremos con un registro de condiciones de cultivo de lechuga. El objetivo es importar la base, reconocer su estructura, corregir los nombres de las variables, detectar y completar un valor faltante y crear dos bases preparadas para los análisis posteriores.

2 Reconocimiento de la base

Antes de comenzar a trabajar en RStudio, vamos a observar el archivo que utilizaremos en esta práctica.

a. Ingresá a la carpeta datos originales del proyecto lechuga.

b. Abrí el archivo lechuga.xlsx.

c. Observá cómo está organizada la información.

Antes de importar el archivo, respondé:

d. ¿Qué tipo de archivo es lechuga.xlsx? e. ¿En qué hoja se encuentran los datos? f. ¿Qué representa cada fila de la base: una planta o una medición de una planta en una fecha?

g. ¿Por qué esta base puede considerarse una base longitudinal o de medidas repetidas?

Pista: cada planta aparece en más de una fila, porque fue medida en distintas fechas.

Los nombres originales contienen mayúsculas, espacios, paréntesis y símbolos de unidad. Para facilitar el trabajo en R, se los normalizará.

Los nuevos nombres, deberían quedar de la siguiente manera:

plant_id
date
temperature_c
humidity_porc
tds_value_ppm
ph_level
growth_days

7 Crear una fecha con formato uniforme

En esta planilla la fecha puede aparecer con formatos distintos.

a. Creá una nueva variable llamada fecha, expresada como fecha de R.

lechuga <- lechuga |>
  mutate(
    fecha = coalesce(
      as.Date(date, format = "%Y-%m-%d"),
      as.Date(date, format = "%m/%d/%Y")
    )
  ) |>
  select(-date)

b. Comprobá que la nueva variable fue creada correctamente:

c. ¿Qué operación realizó select(-date)?

8 Estudiar la estrutura de la base

a. Utilzá la función summary() para obtener un resumen rápido de la base. ¿Qué muestra esta salida?

b. ¿hay datos faltantes?

9 Completar el dato/s faltante/s

a. Identificá la cantidad de datos faltantes y observá a que fila corresponde.

La siguente sentencia identifica cuantos datos hay faltantes

sum(is.na(lechuga))

La siguente sentencia identifica donde está el valor faltante en la variable humidity_porc

lechuga |>
  filter(is.na(humidity_porc))

El dato faltante en la humedad de la planta 1, correspondiente al 25 de agosto de 2023. El valor correcto de humedad es 52.

b. Reemplazá únicamente ese valor faltante:

lechuga <- lechuga |>
  mutate(
    humidity_porc = case_when(
      plant_id == 1 &
        fecha == as.Date("2023-08-25") &
        is.na(humidity_porc) ~ 52,
      TRUE ~ humidity_porc
    )
  )

c. Verificá que no queden datos faltantes y que el valor se haya incorporado en la fila correcta.

10 Consultas breves sobre la base

Respondan mediante código en R:

a. ¿Cuál es el valor de humedad de la planta 3 el 15 de septiembre de 2023?

humedad_3<-lechuga |> filter(plant_id==3,fecha=="2023-09-15") |> select(plant_id, fecha, humidity_porc)
humedad_3

b. ¿Cuáles son la temperatura, el pH y los sólidos disueltos totales de esa misma planta y fecha?

temp_ph_solidos<-lechuga |> filter(plant_id==3, fecha=="2023-09-15") |> select(plant_id,fecha,temperature_c, p_h_level,tds_value_ppm)
temp_ph_solidos

c. ¿Cuál es la primera fecha registrada cronológicamente en la base?

# 7.3 Primera fecha registrada
primera_fecha <- min(lechuga$fecha)
primera_fecha

d. ¿Cuántas plantas fueron medidas en esa primera fecha?


cantidad_plantas <- nrow(lechuga |> filter(fecha == primera_fecha))
cantidad_plantas

e. ¿Qué planta tuvo la mayor humedad en esa primera fecha?


planta_mayor_humedad <- lechuga |> 
  filter(fecha == primera_fecha) |> 
  arrange(desc(humedad)) |> 
  select(plant_id) |> 
  first()
planta_mayor_humedad
  filter(fecha == primera_fecha) |> 
  arrange(desc(humedad)) |> 
  select(plant_id) |> 
  first()
planta_mayor_humedad

11 Guardar la base corregida

a. Guardá la base con nombres limpios, fechas uniformes y el dato faltante corregido dentro de la carpeta datos transformados.

write_csv(
  lechuga,
  "datos transformados/lechuga_limpia.csv"
         )

12 Crear una base con todas las plantas en la primera fecha

a. Primero identificá la primera fecha cronológica y guárdenla en un objeto.

primera_fecha <- min(lechuga$fecha, na.rm = TRUE)
primera_fecha

b. Creá una nueva base que contenga todas las plantas medidas en esa fecha.

lechuga_primera_fecha <- lechuga |>
  filter(fecha == primera_fecha)

lechuga_primera_fecha

c. Comprobá cuántas filas tiene la nueva base y guárdenla dentro de datos transformados.

nrow(lechuga_primera_fecha)

write_csv(
  lechuga_primera_fecha,
  "../datos transformados/lechuga_primera_fecha.csv"
)
