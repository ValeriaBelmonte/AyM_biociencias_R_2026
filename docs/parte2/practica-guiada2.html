1 Propósito

En la Práctica guiada 1 organizamos el proyecto Analisis_agrofood, creamos las carpetas, instalamos tidyverse e importamos la base original. 2 Abrir el proyecto de RStudio

  1. Utilizando el Explorador de archivos de Windows, buscá la carpeta Analisis_agrofood que creaste en la Práctica guiada 1.

  2. Dentro de esa carpeta, localizá el archivo llamado Analisis_agrofood, identificado como RStudio Project File en la columna Tipo. Si Windows muestra las extensiones de los archivos, aparecerá como Analisis_agrofood.Rproj.

  3. Hacé doble clic sobre ese archivo para abrir el proyecto en RStudio.

  4. Una vez abierto el proyecto, comprobá que estén las carpetas datos_originales, datos_transformados y scripts.

  5. Verificá que el archivo Agrofood_co2_emission.csv esté guardado dentro de la carpeta datos_originales.

Importante: continuaremos trabajando en el mismo proyecto que creamos en la Práctica guiada 1. No es necesario crear uno nuevo ni volver a descargar la base de datos.

6.1 Normalizar nombres de variables

Los nombres originales incluyen espacios, mayúsculas y símbolos. Para facilitar el trabajo, usaremos clean_names() del paquete janitor.

6.2 Seleccionar y reordenar columnas

select() conserva columnas sin filtrar filas.

#| label: seleccion-ejemplos
agro |>
  select(area, year, total_emission, average_temperature_c)
agro |>
  select(area:rice_cultivation)
agro |>
  select(area, year, contains("population"))
agro |>
  select(ends_with("fires"))
agro |>
  select(-average_temperature_c)

Las funciones contains() y ends_with() buscan partes de los nombres de columnas. El signo - delante de un nombre excluye esa columna.

Crearemos una base reducida para practicar; la base agro conserva todas sus columnas.

#| label: base-reducida
agro_reducida <- agro |>
  select(
    area, year, rural_population, urban_population,
    total_population_male, total_population_female,
    total_emission, average_temperature_c
  ) |>
  relocate(total_emission, .after = year)

glimpse(agro_reducida)

relocate() cambia el orden de las columnas; .after = year coloca la variable después de year, y .before = year la colocaría antes.

Pregunta 2.4. ¿Qué diferencia hay entre select() y relocate()? ¿Cuántas filas tiene agro_reducida en comparación con agro?

6.3 Filtrar y ordenar observaciones

Mientras select() trabaja con columnas, filter() conserva las filas que cumplen una condición.

#| label: filtros
agro |> filter(area == "Argentina")
agro |> filter(year == 2020)
agro |> filter(area == "Argentina", year == 2020)
agro |>
  filter(area %in% c(
    "Argentina", "Bolivia (Plurinational State of)",
    "Brazil", "Chile", "Paraguay", "Uruguay"
  ))

== comprueba igualdad; %in% comprueba si un valor pertenece a un conjunto.

#| label: ordenar
agro |> arrange(total_emission)
agro |> arrange(area, year)

arrange() ordena filas sin eliminar observaciones. Para ordenar de mayor a menor, se puede usar desc(total_emission).

Pregunta 2.5. ¿Qué diferencia observás entre filter() y arrange()?

7 Transformar variables y controlar los datos

7.1 Crear nuevas variables

mutate() permite crear columnas o modificar las existentes.

#| label: nuevas-variables
agro <- agro |>
  mutate(
    total_population = total_population_male + total_population_female,
    urban_population_percentage =
      100 * urban_population / total_population,
    positive_temperature_change = average_temperature_c > 0
  )

La última variable es lógica (TRUE/FALSE). El porcentaje puede ser faltante cuando faltan componentes; si la población total es cero, debe revisarse antes de interpretar el cociente.

Pregunta 2.6. ¿Qué representa cada una de las tres variables creadas? ¿De qué tipo es positive_temperature_change?

7.2 Detectar valores faltantes y duplicados

En R, NA representa información faltante; no equivale al valor cero.

#| label: faltantes
sum(is.na(agro))

agro |>
  summarise(across(everything(), ~ sum(is.na(.x))))

Para revisar posibles duplicados:

#| label: duplicados
sum(duplicated(agro))

agro |>
  count(area, year) |>
  filter(n > 1)

El primer cálculo detecta filas completamente repetidas; el segundo identifica combinaciones de área y año repetidas, aunque sus demás columnas sean distintas. No elimines duplicados automáticamente: primero investigá su origen.

7.3 Resumir por grupos

#| label: resumen-grupos
agro |>
  group_by(area) |>
  summarise(
    cantidad_anios = n(),
    primer_anio = min(year, na.rm = TRUE),
    ultimo_anio = max(year, na.rm = TRUE),
    .groups = "drop"
  )

group_by() define los grupos y summarise() calcula un resumen para cada uno. En este ejemplo, suponemos que cada área tiene al menos un año registrado.

Pregunta 2.6. ¿Todos los países tienen la misma cantidad de registros anuales? ¿Qué información te permite averiguarlo?

8 Construir una nueva base para América del Sur

Nuestro objetivo es conservar los registros correspondientes a los países de América del Sur y crear la variable grupo_region con tres categorías: Argentina, Países limítrofes y Otros países de América del Sur.

Primero filtramos las áreas que queremos conservar. En este ejercicio se incluyen los países soberanos de América del Sur; no se incluyen las islas Malvinas/Falkland como un país independiente.

#| label: sudamerica
agro_sudamerica <- agro |>
  filter(area %in% c(
    "Argentina", "Bolivia (Plurinational State of)",
    "Brazil", "Chile", "Colombia", "Ecuador",
    "Guyana", "Paraguay", "Peru", "Suriname",
    "Uruguay", "Venezuela (Bolivarian Republic of)"
  ))

A continuación creamos la clasificación regional y ordenamos las observaciones.

#| label: grupo-region
agro_sudamerica <- agro_sudamerica |>
  mutate(
    grupo_region = case_when(
      area == "Argentina" ~ "Argentina",
      area %in% c(
        "Bolivia (Plurinational State of)",
        "Brazil", "Chile", "Paraguay", "Uruguay"
      ) ~ "Países limítrofes",
      TRUE ~ "Otros países de América del Sur"
    )
  ) |>
  arrange(area, year)

case_when() asigna un valor de acuerdo con las condiciones, evaluadas de arriba hacia abajo. TRUE contempla los casos restantes.

Comprobamos el resultado:

#| label: comprobar-region
agro_sudamerica |> distinct(area, grupo_region) |> arrange(grupo_region, area)
agro_sudamerica |> count(grupo_region)

Pregunta 2.7. ¿Cuántos países distintos aparecen en la nueva base? ¿Qué países quedaron clasificados como limítrofes?

9 Guardar y verificar la nueva base

Guardá la base transformada en la carpeta datos_transformados, creada en la Práctica guiada 1.

#| label: guardar-csv
write_csv(
  agro_sudamerica,"../datos_transformados/agro_sudamerica.csv"
)

write_csv() guarda un archivo CSV; no reemplaza ni modifica el archivo original de datos originales.

Comprobá desde el explorador de archivos de RStudio que agro_sudamerica.csv aparezca en la carpeta correspondiente. Para verificar que puede importarse otra vez, leemos el archivo con otro nombre de objeto:

Ampliación opcional: otros formatos de importación y guardado

Además de archivos CSV, R permite importar datos desde Excel y otros formatos.

Tipo de archivo Función Paquete
CSV delimitado por comas read_csv() readr (incluido en tidyverse)
CSV delimitado por punto y coma read_csv2() readr (incluido en tidyverse)

Para importar Excel, primero instalá readxl (solo si hace falta) y luego cargalo:

#| eval: false
# install.packages("readxl")
library(readxl)

Resultado de la práctica

Terminaste con una base de datos de América del Sur que contiene variables procesadas y una clasificación regional. La conservamos como agro_sudamerica.csv en datos_transformados para continuar con el análisis exploratorio en la próxima práctica.

10 ¿Qué aprendimos en esta práctica?

Aprendimos a importar, reconocer, limpiar y transformar datos en R utilizando los paquetes tidyverse y janitor. Trabajamos con funciones para seleccionar variables, filtrar y ordenar observaciones, crear nuevas variables y obtener resúmenes por grupos. También aprendimos a identificar valores faltantes y duplicados. Finalmente, construimos una base de datos de América del Sur y la guardamos en formato CSV para utilizarla en las próximas prácticas.

```r
      area == "Argentina" ~ "Argentina",
      area %in% c(
        "Bolivia (Plurinational State of)",
        "Brazil", "Chile", "Paraguay", "Uruguay"
      ) ~ "Países limítrofes",
      TRUE ~ "Otros países de América del Sur"
    )
  ) |>
  arrange(area, year)
```

`case_when()` asigna un valor de acuerdo con las condiciones, evaluadas de arriba hacia abajo. `TRUE` contempla los casos restantes.



## Ampliación opcional: otros formatos de importación y guardado

Además de archivos CSV, R permite importar datos
desde Excel y otros formatos.


| Tipo de archivo | Función | Paquete |
|---|---|---|
| CSV delimitado por comas | `read_csv()` | `readr` (incluido en `tidyverse`) |
| CSV delimitado por punto y coma | `read_csv2()` | `readr` (incluido en `tidyverse`) |
| Excel (`.xlsx`, `.xls`) | `read_excel()` | `readxl` |
| Texto delimitado | `read_delim()` | `readr` |
| Objeto R (`.rds`) | `readRDS()` | R base |

`read_csv2()` utiliza por defecto punto y coma como separador y coma como marca decimal.

Para importar Excel, primero instalá `readxl` (solo si hace falta) y luego cargalo:

```r
#| eval: false
# install.packages("readxl")
library(readxl)
datos_excel <- read_excel("../datos originales/archivo.xlsx")
```
