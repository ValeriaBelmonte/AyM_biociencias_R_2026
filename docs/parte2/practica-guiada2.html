2 1. Preparación del entorno e importación

Los paquetes se instalan una única vez en la computadora. En cambio, deben cargarse cada vez que se inicia una nueva sesión de trabajo en R.

install.packages("tidyverse")
install.packages("janitor")
  1. Importar datos significa leer un archivo externo y convertirlo en un objeto que R pueda utilizar.
agro <- read_csv("../datos originales/Agrofood_co2_emission.csv")

A partir de este momento, agro será nuestro objeto de trabajo. Modificarlo no cambia automáticamente el archivo CSV original.

  1. Reconocimiento de la estructura de la base

En esta base, cada fila representa información de un área o país en un año determinado. Las columnas representan variables, por ejemplo, las emisiones por distintos rubros, la población y la temperatura media.

dim(agro)

nrow(agro)

ncol(agro)
glimpse(agro)

La función glimpse() permite observar los nombres de las variables, sus tipos y algunos de sus valores.

  1. Limpieza de nombres

Los nombres originales contienen espacios, mayúsculas, paréntesis y símbolos. Para trabajar de manera más sencilla, los normalizaremos.

agro <- agro |>
  clean_names()

names(agro)

Por ejemplo:

Area → area
Year → year
Average Temperature °C → average_temperature_c

Total Population - Female → total_population_female

A partir de este punto se utilizarán los nombres limpios.

  1. Tipos de variables

En la base predominan variables de texto y variables numéricas.

area contiene nombres de países o regiones. year representa el año de cada registro. Las emisiones, la población y la temperatura son variables numéricas.

class(agro$area)

class(agro$year)

class(agro$total_emission)

Aunque year está expresada mediante números, representa el tiempo y se mantendrá como variable numérica para estudiar posteriormente su evolución.

  1. Selección y reordenamiento de variables

Seleccionar variables significa conservar determinadas columnas de la base. Esta operación no elimina filas.

  1. seleccionar algunas variables especificas: area, year, total_emission, average_temperature_c
agro |>
  select(area, year, total_emission, average_temperature_c)
  1. Seleccionar las varaialbes desde áreas hasta rice_cultivation
agro |>
  select(area:rice_cultivation)

Selccionar las variables que tienen una determinada parlabra. Ejemplo, “population” Observación: la palabar debe ir entre comillas

agro |>
  select(area, year, contains("population"))

Seleccionar las variables que terminan en una deteminada palabra, por ejemplo “fires”

agro |>
  select(ends_with("fires"))
  1. Eliminar una variable se utliza la función select() y se escribe la varaible precedida por el signo -
agro |>
  select(-average_temperature_c)

Podemos crear una base reducida para trabajar con algunas variables seleccionadas.

agro_reducida <- agro |>
  select(
    area,
    year,
    rural_population,
    urban_population,
    total_population_male,
    total_population_female,
    total_emission,
    average_temperature_c
  ) |>
  relocate(total_emission, .after = year)

relocate(total_emission, .after = year) sirve para ordenar un variable. Se puede adicionar

.after =…-> después de…

.besfore=… -> antes de…

  1. Filtrado y ordenamiento de observaciones

Mientras select() trabaja con columnas, filter() permite conservar las filas que cumplen una condición.

agro |>
  filter(area == "Argentina")
agro |>
  filter(year == 2020)
agro |>
  filter(
    area == "Argentina",
    year == 2020
  )
agro |>
  filter(
    area %in% c(
      "Argentina",
      "Bolivia (Plurinational State of)",
      "Brazil",
      "Chile",
      "Paraguay",
      "Uruguay"
    )
  )
agro |>
  arrange(total_emission)
agro |>
  arrange(area, year)
  1. Creación y recodificación de variables

La función mutate() permite crear nuevas variables o modificar las existentes.

agro <- agro |>
  mutate(
    total_population =
      total_population_male + total_population_female,
    
    urban_population_percentage =
      100 * urban_population / total_population,
    
    positive_temperature_change =
      average_temperature_c > 0
  )

También podemos crear una variable para distinguir a Argentina de otros paises

agro <- agro |>
  mutate(
    grupo_region = case_when(
      area == "Argentina" ~ "Argentina",
      
      TRUE ~ "Otros países o regiones"
    )
  )
  1. Valores faltantes y duplicados

Un valor faltante se representa en R mediante NA. No significa que el valor sea cero, sino que la información no está disponible.

sum(is.na(agro))
agro |>
  summarise(
    across(
      everything(),
      ~ sum(is.na(.x))
    )
  )

Para detectar si existen filas completamente duplicadas:

sum(duplicated(agro))
agro |>
  count(area, year) |>
  filter(n > 1)

En esta base, debería haber como máximo una observación por combinación de área y año.

Antes de eliminar duplicados, es necesario investigar por qué aparecen.

  1. Resúmenes agrupados iniciales

La combinación de group_by() y summarise() permite organizar y resumir información para distintos grupos.

agro |>
  group_by(area) |>
  summarise(
    cantidad_anios = n(),
    primer_anio = min(year),
    ultimo_anio = max(year)
  )

En las próximas clases utilizaremos estas mismas funciones para calcular medidas descriptivas y comparar las emisiones entre países y rubros.

  1. Construcción y guardado de la base limpia

Finalmente, construiremos una versión ordenada de la basecon los países de América del Sur incluidos, que utilizaremos en las clases siguientes.

agro_sudamerica <- agro |>
  filter(
    area %in% c(
      "Argentina",
      "Bolivia (Plurinational State of)",
      "Brazil",
      "Chile",
      "Colombia",
      "Ecuador",
      "Falkland Islands (Malvinas)",
      "Guyana",
      "Paraguay",
      "Peru",
      "Suriname",
      "Uruguay",
      "Venezuela (Bolivarian Republic of)"
    )
  )

Creamos una nueva variable de clasifiación para idenitificar Argentina, los paises límitrofes y los restantes

agro_sudamerica <-agro_sudamerica  |>
  mutate(
    grupo_region = case_when(
      area == "Argentina" ~ "Argentina",
      
      area %in% c(
        "Bolivia (Plurinational State of)",
        "Brazil",
        "Chile",
        "Paraguay",
        "Uruguay"
      ) ~ "Países limítrofes",
      
      TRUE ~ "Otros países de América del Sur"
    )
  ) |>
  arrange(area, year)
write_csv(
  agro_sudamerica,
  "../datos transformados/agro_sudamerica.csv"
)

También es posible guardarla como objeto de R. Este formato conserva mejor las clases de las variables.

saveRDS(
  agro_sudamerica,
  "../datos transformados/agro_sudamerica.rds"
)
agro_sudamerica2<- readRDS(
  "../datos transformados/agro_sudamerica.rds"
)

Al finalizar esta etapa, contaremos con una base limpia, ordenada y preparada para realizar tablas, gráficos y análisis descriptivos.agro |> select(-average_temperature_c)

Podemos crear una base reducida para trabajar con algunas variables seleccionadas.
