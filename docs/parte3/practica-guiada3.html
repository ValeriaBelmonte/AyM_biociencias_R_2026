Práctica guiada 3

En esta práctica aplicamos herramientas del análisis exploratorio de datos (EDA) a la base agro_sudamerica.csv. El objetivo no es obtener conclusiones definitivas ni ajustar modelos, sino conocer los datos, detectar problemas y formular preguntas.

Nos concentramos en los residuos de los cultivos. Construiremos tablas y gráficos para ver cómo se distribuye la variable, comparar áreas, observar su evolución en el tiempo y explorar su relación con emisiones resultantes de la quema o descomposición de material vegetal sobrante después de la cosecha de cultivos (crop_residues) En cada actividad no basta con ejecutar el código: interpretá los resultados. ¿Qué muestra la tabla? ¿Qué patrón aparece en el gráfico? ¿Qué dudas o preguntas nuevas surgen?

La función ls() devuelve los nombres de los objetos existentes en el entorno de trabajo, mientras que rm() permite eliminarlos.

Por lo tanto, rm(list = ls()) elimina los objetos del entorno de trabajo actual.

Importante: esta instrucción no elimina los archivos guardados en las carpetas del proyecto. Solamente elimina los objetos que se encuentran cargados en la sesión de R.

3.1 Introducción a esquisse

El paquete esquisse(Meyer & Perrier, 2025) permite crear gráficos de manera interactiva mediante una interfaz visual, sin necesidad de escribir inicialmente todo el código.

Esta herramienta se basa en ggplot2 y permite:

  • Seleccionar las variables que se desean representar.
  • Elegir diferentes tipos de gráficos.
  • Modificar colores, títulos y otras características.
  • Recuperar el código R utilizado para construir el gráfico.

Una de sus principales ventajas es que permite explorar diferentes representaciones gráficas y, posteriormente, incorporar el código generado a un documento reproducible.

Instalación del paquete

Para instalar esquisse, ejecutá la siguiente instrucción en la consola de RStudio:

install.packages("esquisse")

Recordá que la instalación se realiza una sola vez, mientras que la carga del paquete debe efectuarse en cada sesión en la que se necesite utilizarlo.

Los argumentos de ggsave() son:

Argumento Descripción
filename Nombre y ubicación del archivo
plot Objeto gráfico que queremos guardar
width Ancho de la imagen
height Alto de la imagen
units Unidad de medida ("cm", "in" o "mm")
dpi Resolución de la imagen en puntos por pulgada
bg Color de fondo de la imagen
Tamaño y resolución de una imagen

El tamaño corresponde a las dimensiones físicas del gráfico, mientras que la resolución determina la cantidad de píxeles por unidad de longitud.

Como orientación:

  • 96 dpi: adecuado para visualización en pantalla.
  • 150 dpi: resolución intermedia.
  • 300 dpi: utilizado habitualmente para impresión y publicaciones.

Una resolución mayor no modifica los datos representados, pero permite obtener una imagen con más píxeles cuando se mantiene el mismo tamaño físico.

Para recordar

Guardar un gráfico como objeto permite reutilizarlo, modificarlo y exportarlo sin necesidad de volver a escribir todo el código.

Con ggsave() podemos controlar el formato, tamaño y resolución de la imagen según el uso que necesitemos darle.

4 Actividad 4. ¿Cómo se comparan las emisiones de residuos de cultivos entre Argentina y Brasil?

En la actividad anterior exploramos gráficamente la evolución de las emisiones provenientes de residuos de cultivos (crop_residues) en Argentina y Brasil.

Ahora utilizaremos medidas estadísticas descriptivas para resumir y comparar las emisiones de ambos países durante el período estudiado.

4.1 Cálculo de medidas resumen

Calcularemos las siguientes medidas:

  • Media: promedio de las emisiones registradas.
  • Mediana: valor que divide las observaciones ordenadas en dos partes iguales.
  • Desvío estándar: medida de dispersión de los valores respecto de la media.
  • Mínimo y máximo: valores extremos observados.

Para obtener estas medidas utilizaremos funciones del paquete dplyr, incluido en tidyverse.

#| label: resumen-paises

resumen_paises <- agro_sudamerica |>
  filter(area %in% c("Argentina", "Brazil")) |>
  group_by(area) |>
  summarise(
    n = sum(!is.na(crop_residues)),
    media = mean(crop_residues, na.rm = TRUE),
    mediana = median(crop_residues, na.rm = TRUE),
    desvio = sd(crop_residues, na.rm = TRUE),
    minimo = min(crop_residues, na.rm = TRUE),
    maximo = max(crop_residues, na.rm = TRUE),
    .groups = "drop"
  )

resumen_paises

La función group_by(area) agrupa las observaciones según el país, mientras que summarise() calcula las medidas estadísticas para cada grupo.

El argumento na.rm = TRUE indica que los valores faltantes (NA) deben excluirse del cálculo.

6 Actividad 7. Preparación de los datos para la próxima práctica

6.1 Seleccionar las observaciones y variables

En la actividad anterior observamos la evolución temporal de las emisiones provenientes de residuos de cultivos en Argentina y Brasil.

Para la próxima práctica, trabajaremos con el período 2009–2020, en el que los gráficos exploratorios sugieren una tendencia aproximadamente lineal. Esta selección nos permitirá introducir los modelos de regresión lineal simple.

Utilizaremos las funciones filter() y select() del paquete dplyr para seleccionar los países, los años y las variables de interés.

#| label: preparar-datos-regresion

agro_regresion <- agro_sudamerica |>
  filter(area %in% c("Argentina", "Brazil")) |>
  filter(year > 2008) |>
  select(area, year, crop_residues) |>
  arrange(area, year)

La función filter() permite seleccionar las observaciones correspondientes a los dos países, mientras que select() conserva únicamente las variables necesarias.

Por su parte, arrange() ordena los registros por país y año.

### Tamaño y resolución de una imagen

El **tamaño** corresponde a las dimensiones físicas del gráfico, mientras que la **resolución** determina la cantidad de píxeles por unidad de longitud.

Como orientación:

- **96 dpi:** adecuado para visualización en pantalla.
- **150 dpi:** resolución intermedia.
- **300 dpi:** utilizado habitualmente para impresión y publicaciones.

Una resolución mayor no modifica los datos representados, pero permite obtener una imagen con más píxeles cuando se mantiene el mismo tamaño físico.

## Actividad 4. ¿Cómo se comparan las emisiones de residuos de cultivos entre Argentina y Brasil?

En la actividad anterior exploramos gráficamente la evolución de las emisiones provenientes de residuos de cultivos (`crop_residues`) en Argentina y Brasil.

Ahora utilizaremos **medidas estadísticas descriptivas** para resumir y comparar las emisiones de ambos países durante el período estudiado.

### Cálculo de medidas resumen

Calcularemos las siguientes medidas:

- **Media:** promedio de las emisiones registradas.
- **Mediana:** valor que divide las observaciones ordenadas en dos partes iguales.
- **Desvío estándar:** medida de dispersión de los valores respecto de la media.
- **Mínimo y máximo:** valores extremos observados.

Para obtener estas medidas utilizaremos funciones del paquete `dplyr`, incluido en `tidyverse`.

``` r
#| label: resumen-paises

resumen_paises <- agro_sudamerica |>
  filter(area %in% c("Argentina", "Brazil")) |>
  group_by(area) |>
  summarise(
    n = sum(!is.na(crop_residues)),
    media = mean(crop_residues, na.rm = TRUE),
    mediana = median(crop_residues, na.rm = TRUE),
    desvio = sd(crop_residues, na.rm = TRUE),
    minimo = min(crop_residues, na.rm = TRUE),
    maximo = max(crop_residues, na.rm = TRUE),
    .groups = "drop"
  )

resumen_paises
```

La función `group_by(area)` agrupa las observaciones según el país, mientras que `summarise()` calcula las medidas estadísticas para cada grupo.

El argumento `na.rm = TRUE` indica que los valores faltantes (`NA`) deben excluirse del cálculo.

#| label: preparar-datos-regresion

agro_regresion <- agro_sudamerica |>

## ¿Qué aprendimos en esta práctica?

En esta práctica aprendimos a realizar un **análisis exploratorio de datos (EDA)** utilizando herramientas de R y RStudio. Reconocimos la estructura de una base de datos, exploramos la evolución temporal de las emisiones provenientes de residuos de cultivos y comparamos su comportamiento en Argentina y Brasil. Utilizamos `esquisse` y `ggplot2` para construir gráficos, `ggsave()` para guardarlos con diferentes tamaños y resoluciones, y funciones de `dplyr` para calcular medidas estadísticas descriptivas. También aprendimos a presentar tablas con `flextable` y a utilizar la inteligencia artificial como herramienta de apoyo, evaluando críticamente sus respuestas. Finalmente, seleccionamos y guardamos una nueva base de datos que utilizaremos en la próxima práctica para introducir los **modelos de regresión lineal**.
