1 Preparación del entorno de trabajo

1.1 Fundamento teórico

Un análisis reproducible debe desarrollarse dentro de un proyecto. El proyecto permite mantener organizados los datos, scripts, gráficos e informes, y evita depender de rutas absolutas asociadas a una computadora particular.

Una posible estructura es:

analisis_agrofood/ ├── datos/ │
└── Agrofood_co2_emission.csv ├── scripts/ ├── resultados/ ├── figuras/ └── informes | └── informe.qmd

En RStudio creamos el nuevo proyecto y lo guardamos en la carpeta principal analisis_agrofood:

File → New Project → New Directory → New Project

1.2 Insalación de Paquetes

Instalaremos algunos paquetes por primera vez, para ello abriremos el chunk en en R Para ello buscaremos en el icono o con el teclado contrl+ alt+ i y copiamos los paquetes que debemos isntalar

Dentro de los Chunck se pueden escribir aclaraciones o indicaciones, siempre anteponiendo el # de esta manera el programa ignora lo escrito.

Code

# si no lo tiene
#install.packages("tidyverse") 
#install.packages("janitor") 
#install.packages("skimr")

Los paquetes se instalan una sola vez

Además, se les puede asignar un nombres a los Chunk

2 3. Importación de la base de datos

2.1 Fundamento teórico

Importar datos significa leer un archivo externo y convertirlo en un objeto que R pueda utilizar.

Para archivos CSV puede emplearse read_csv(). Esta función genera un objeto de tipo tibble, una versión moderna de un data frame.

2.2 Código en R

Suponiendo que el archivo está dentro de la carpeta datos:

Code 
agro <- read_csv("../datos originales/Agrofood_co2_emission.csv")
Rows: 6965 Columns: 31
── Column specification ────────────────────────────────────────────────────────
Delimiter: ","
chr  (1): Area
dbl (30): Year, Savanna fires, Forest fires, Crop Residues, Rice Cultivation...

ℹ Use `spec()` to retrieve the full column specification for this data.
ℹ Specify the column types or set `show_col_types = FALSE` to quiet this message.

Para comprobar que el objeto fue creado:

Code 
view(agro)

También puede observarse en el panel Environment de RStudio.

2.3 Diferencia entre objeto y archivo

El archivo original permanece almacenado en la computadora como Agrofood_co2_emission.csv

El objeto creado dentro de R se denomina:

agro

Modificar el objeto agro no altera automáticamente el archivo CSV original.

3 4. Primera inspección de la base

3.1 Fundamento teórico

Antes de modificar una base, se debe conocer:

  • cuántas filas tiene;

  • cuántas columnas contiene;

  • cómo se llaman las variables;

  • qué tipo de información almacena cada variable;

  • si existen valores faltantes;

  • si se observan errores evidentes.

Cada fila de esta base representa una combinación de país o área y año. Cada columna representa una variable.
