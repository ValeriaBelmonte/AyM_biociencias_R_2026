1 Práctica 1: diseño completamente al azar (roña de la papa)

En el cuadro 4.1 del libro Diseño de experimentos (Cochran & Cox, 1957) se presentan los resultados de un experimento sobre la roña de la papa. La roña no prospera en suelos muy ácidos, así que se aplicó azufre para acidificarlos. Se comparan el testigo (sin tratamiento) y 6 combinaciones de dosis (300, 600 y 1200 kg/ha) aplicadas en otoño (F) o primavera (S).

Notación: 0 = testigo; F = otoño; S = primavera. Los números 3, 6 y 12 son las cantidades de azufre en 100 kg/ha. La variable de respuesta es el índice de roña (inf).

1.1 Paso 1. Pregunta de investigación e hipótesis

Pregunta de investigación: ¿el azufre cambia el índice de roña respecto del testigo, y el momento de aplicación (otoño o primavera) importa?

Las hipótesis para el ANOVA son:

\[H_0: \mu_1 = \mu_2 = \cdots = \mu_7 \qquad H_1: \text{al menos una media difiere}\]

Pregunta 1.1: ¿qué significa \(H_0\) en palabras, para este experimento?

1.2 Paso 2. Modelo y supuestos

\[Y_{ij} = \mu + \tau_i + \varepsilon_{ij}, \qquad \varepsilon_{ij} \sim N(0, \sigma^2) \text{ independientes}\]

  • \(Y_{ij}\): índice de roña de la parcela \(j\) con el tratamiento \(i\).
  • \(\tau_i\): efecto del tratamiento \(i\).

En el contexto del modelo, las hipótesis quedan como: \[H_0: \tau_1 = \tau_2 = \cdots = \tau_7=0 \qquad H_1: \tau_i\neq0 \text{ para algún} \quad i\]

Pregunta 1.2: la asignación de los tratamientos a las parcelas fue completamente al azar. ¿Qué implica esto para el supuesto de independencia?

1.3 Paso 3. Exploración

1.4 Paso 4. Estimación

Con el modelo ajustado, evaluamos si el tratamiento tiene efecto sobre el índice de roña. La tabla de ANOVA prueba \(H_0\): todas las medias de tratamiento son iguales. La columna F compara la variabilidad entre tratamientos con la variabilidad dentro de ellos, y el p-valor indica qué tan compatible es el resultado con \(H_0\).

#| label: anova-papa
anova_papa <- aov(inf ~ trt, data = datos_papas)
anova(anova_papa)

El valor de F es 3.6081 y su p valor es 0.01026.

1.5.1 Contrastes planificados (continuación del paso 4)

Cuando las preguntas son específicas, es más informativo probar contrastes que comparar todos los pares. En este experimento interesan dos:

  • Testigo contra azufre: ¿el azufre, en cualquier dosis y momento, reduce la roña?
  • Otoño contra primavera: ¿el momento de aplicación cambia el efecto?

Los coeficientes de cada contraste suman cero. Para que el primero compare el testigo contra los seis tratamientos con azufre, el testigo tiene coeficiente \(-6\) y los demás \(+1\):

#| label: contrastes-papa
# Orden de niveles esperado: F3, F6, F12, 0, S3, S6, S12
# Verificar con levels(datos_papas$trt) antes de correr
contrasts(datos_papas$trt) <- cbind(
  c1 = c(1, 1, 1, -6, 1, 1, 1),    # testigo contra azufre
  c2 = c(-1, -1, -1, 0, 1, 1, 1)   # otoño contra primavera
)

m1 <- aov(inf ~ trt, data = datos_papas)
summary(m1, split = list(trt = list("Testigo vs azufre" = 1,
                                    "Otoño vs primavera" = 2)))

2 Práctica 2: la prueba t de Student como modelo lineal (roña de la papa)

Vamos a comparar el testigo contra todas las parcelas con azufre juntas. Son dos grupos, así que la prueba t de Student es la herramienta clásica. Lo que queremos mostrar es que esa prueba es un caso particular del modelo lineal, el mismo que usamos en el ANOVA.

2.1 Paso 1. Pregunta e hipótesis

Pregunta de investigación: ¿el testigo tiene un índice de roña distinto del promedio de las parcelas con azufre?

\[H_0: \mu_{\text{testigo}} = \mu_{\text{azufre}} \qquad H_1: \mu_{\text{testigo}} \neq \mu_{\text{azufre}}\]

2.2 Paso 3. Exploración

Creamos el factor de dos grupos a partir de la base de la práctica 1:

#| label: dos-grupos
datos_t <- datos_papas |>
  mutate(grupo = if_else(as.character(trt) == "O","Testigo", "Azufre"),
         grupo = factor(grupo, levels = c("Testigo", "Azufre")))
datos_t

Pregunta 2.1: ¿Cuantos datos hay por tratamamiento

table(datos_t$grupo)

Pregunta 2.2: Realiza un gráfico exploratorio

#| label: boxplot-t
ggplot(datos_t, aes(x = grupo, y = inf, fill = grupo)) +
  geom_boxplot(alpha = 0.5) +
  geom_jitter(width = 0.1, alpha = 0.6) +
  labs(title="Box plot Índice de roña  según tratamiento",
       x="tratameiento", 
       y= "Índice de roña")+
  theme_minimal() +
  theme(legend.position = "none")

Pregunta 2.3: ¿la diferencia entre los grupos se ve a simple vista? ¿Cuál grupo tiene mayor dispersión?

Medias y desvíos por grupo:

#| label: resumen-t
datos_t |>
  group_by(grupo) |>
  summarise(n = n(), media = mean(inf), desvio = sd(inf), .groups = "drop")

2.3 Paso 4. Estimación: tres formas que dan el mismo resultado

Pregunta 2.4: ¿El indice de roña en la papa difiere al aplicar Azufre?

Forma A: prueba t clásica con varianzas iguales

#| label: T Student
t.test(inf ~ grupo,
       mu = 0,  # Hipótesis nula 
       alternative = "two.sided",# Hipótesis alternativa  puede ser"two.sided", "less", "greater"
       var.equal = TRUE, # supone igualdad de varianzas 
       conf.level = 0.95, # nivel de confianza R usa nivel de confianz uy no die significación 
       data = datos_t # base de datos 
       )

Forma B: prueba de Welch con varianzas Diferentes

#| label: Test Welch

t.test(inf ~ grupo,
       mu = 0,  # Hipótesis nula 
       alternative = "two.sided",# Hipótesis alternativa  puede ser"two.sided", "less", "greater"
       var.equal = FALSE, # supone igualdad de varianzas 
       conf.level = 0.95, # nivel de confianza R usa nivel de confianz uy no die significación 
       data = datos_t # base de datos 
       )
#| label: prueba  T por defecto 
t.test(inf ~ grupo,
       data = datos_t,
       )

¿Cómo decido si las varianzas son iguales o diferentes?

var.test(inf~grupo, data=datos_t)
#| label: más inforamción por  el test t
help (t.test)

Forma B: modelo lineal con lm()

2.4 Paso 2. Modelo

Con dos grupos, el modelo lineal se escribe con una variable indicadora \(x_i\), que vale 1 si la parcela recibió azufre y 0 si es testigo:

\[Y_i = \beta_0 + \beta_1 x_i + \varepsilon_i, \qquad \varepsilon_i \sim N(0, \sigma^2)\]

  • \(\beta_0 = \mu_{\text{testigo}}\): media del testigo.
  • \(\beta_1 = \mu_{\text{azufre}} - \mu_{\text{testigo}}\): diferencia entre las medias.

Así, \(H_0: \mu_{\text{testigo}} = \mu_{\text{azufre}}\) es equivalente a \(H_0: \beta_1 = 0\).

#| label: t-lm
modelo_t <- lm(inf ~ grupo, data = datos_t)
summary(modelo_t)

Pregunta 2.5: en la salida de summary(), ¿qué valor corresponde a \(\beta_0\) y cuál a \(\beta_1\)? Comparalos con las medias del paso 3.

Forma C: ANOVA sobre el mismo modelo

#| label: t-anova
anova(modelo_t)

Pregunta 2.6: compará el valor de \(t\) de t.test() y de summary(), y el valor de \(F\) del ANOVA. ¿Qué relación encontrás entre \(F\) y \(t^2\)?

Pregunta 2.7: ¿los p-valores de las tres formas coinciden? ¿Por qué debería ser así?

#| label: validacion-t
#| fig-width: 8
#| fig-height: 7
par(mfrow = c(2, 2))
plot(modelo_t)
par(mfrow = c(1, 1))

shapiro.test(residuals(modelo_t))
car::leveneTest(inf ~ grupo, data = datos_t)

3 Práctica 3: diseño en bloques (remolacha azucarera)

El experimento compara fertilizantes en la producción de remolacha azucarera. Los tratamientos combinan superfosfato (P), cloruro de potasio (K) y nitrato de sodio (N). Las parcelas se agruparon en bloques según el terreno, para que la variabilidad entre bloques no quede en el error.

Variables de la base cochran.beets:

  • fert: tratamiento de fertilizante.
  • block: bloque.
  • yield: rendimiento (toneladas/acre).
  • plants: número de plantas por parcela.

3.1 Paso 1. Pregunta e hipótesis

Pregunta de investigación: ¿el tipo de fertilizante cambia el rendimiento de la remolacha, una vez descontada la variabilidad entre bloques?

\[H_0: \tau_1 = \cdots = \tau_k = 0 \qquad H_1: \text{al menos un } \tau_i \neq 0\]

Pregunta 3.1: ¿por qué el bloque no es la pregunta principal, aunque lo incluyamos en el modelo?

3.2 Paso 2. Modelo

\[Y_{ij} = \mu + \tau_i + \beta_j + \varepsilon_{ij}, \qquad \varepsilon_{ij} \sim N(0, \sigma^2)\]

  • \(\tau_i\): efecto del fertilizante \(i\).
  • \(\beta_j\): efecto del bloque \(j\).

Pregunta 3.2: ¿cuántas observaciones hay por combinación de fertilizante y bloque?

3.3 Paso 3. Exploración

#| label: carga-remolacha
datos_remolacha <- cochran.beets |>
  mutate(fert = factor(fert), block = factor(block))

str(datos_remolacha)
summary(datos_remolacha)

Pregunta 3.2: Realiza un gráfico exploratorio

Boxplot del rendimiento según fertilizante:

#| label: boxplot-fert
ggplot(datos_remolacha, aes(x = fert, y = yield, fill = fert)) +
  geom_boxplot(alpha = 0.5) +
  labs(x = "Fertilizante", y = "Rendimiento (toneladas/acre)",
       title = "Rendimiento según fertilizante") +
  theme_minimal() +
  theme(legend.position = "none",
        axis.text.x = element_text(angle = 45, hjust = 1))

3.4 Paso 4. Estimación

Pregunta 3.3 ¿Existe diferencias en el rendimiento según los fertilizantes aplicado?

#| label: anova-remolacha
modelo_remolacha <- aov(yield ~ fert + block, data = datos_remolacha)
anova(modelo_remolacha)

Pregunta 3.4: ¿qué p-valor tiene el fertilizante? ¿Y el bloque? ¿Por qué el p-valor del bloque no se debe analizar?

Comparaciones de medias de fertilizantes, con ajuste de Tukey:

#| label: tukey-remolacha
medias_rem <- emmeans(modelo_remolacha, ~ fert)
pairs(medias_rem, adjust = "tukey")

3.4.1 ¿Hay interacción entre tratamiento y bloque?

Con una sola observación por combinación fertilizante-bloque, el modelo no puede estimar la interacción: no quedan grados de libertad para el error.

Pregunta 3.5: verificá la cantidad de observaciones por combinación con table(datos_remolacha$fert, datos_remolacha$block). ¿Qué pasa con los grados de libertad si intentás ajustar yield ~ fert * block?

Para evaluar si el efecto del fertilizante depende del bloque, se usa la prueba de no aditividad de Tukey, que tiene un grado de libertad. Se calcula con el paquete agricolae:

#| label: no-aditividad
#| eval: false
# install.packages("agricolae")
#| label: no-aditividad

# Cuadrado medio del error
cm_error <- anova(modelo_remolacha)["Residuals", "Mean Sq"]

# Grados de libertad del error
gl_error <- df.residual(modelo_remolacha)

# Prueba de no aditividad de Tukey
agricolae::nonadditivity(
  y = datos_remolacha$yield,
  factor1 = datos_remolacha$fert,
  factor2 = datos_remolacha$block,
  df = gl_error,
  MSerror = cm_error
)

# Práctica 2: la prueba t de Student como modelo lineal (roña de la papa)

Vamos a comparar el **testigo** contra **todas las parcelas con azufre juntas**. Son dos grupos, así que la prueba t de Student es la herramienta clásica. Lo que queremos mostrar es que esa prueba es un caso particular del modelo lineal, el mismo que usamos en el ANOVA.

**Forma B: modelo lineal con `lm()`**

## Paso 2. Modelo

Con dos grupos, el modelo lineal se escribe con una variable indicadora $x_i$, que vale 1 si la parcela recibió azufre y 0 si es testigo:

$$Y_i = \beta_0 + \beta_1 x_i + \varepsilon_i, \qquad \varepsilon_i \sim N(0, \sigma^2)$$

- $\beta_0 = \mu_{\text{testigo}}$: media del testigo.
- $\beta_1 = \mu_{\text{azufre}} - \mu_{\text{testigo}}$: diferencia entre las medias.

Así, $H_0: \mu_{\text{testigo}} = \mu_{\text{azufre}}$ es equivalente a $H_0: \beta_1 = 0$.

``` r
#| label: t-lm
modelo_t <- lm(inf ~ grupo, data = datos_t)
summary(modelo_t)
```

**Forma C: ANOVA sobre el mismo modelo**

``` r

```

# Práctica 3: diseño en bloques (remolacha azucarera)

Variables de la base `cochran.beets`:

### ¿Hay interacción entre tratamiento y bloque?

Con una sola observación por combinación fertilizante-bloque, el modelo no puede estimar la interacción: no quedan grados de libertad para el error.

**Pregunta 3.5:** verificá la cantidad de observaciones por combinación con `table(datos_remolacha$fert, datos_remolacha$block)`. ¿Qué pasa con los grados de libertad si intentás ajustar `yield ~ fert * block`?

Para evaluar si el efecto del fertilizante depende del bloque, se usa la **prueba de no aditividad de Tukey**, que tiene un grado de libertad. Se calcula con el paquete `agricolae`:

``` r
#| label: no-aditividad
#| eval: false
# install.packages("agricolae")
#| label: no-aditividad

# Cuadrado medio del error
cm_error <- anova(modelo_remolacha)["Residuals", "Mean Sq"]

# Grados de libertad del error
gl_error <- df.residual(modelo_remolacha)

# Prueba de no aditividad de Tukey
agricolae::nonadditivity(
  y = datos_remolacha$yield,
  factor1 = datos_remolacha$fert,
  factor2 = datos_remolacha$block,
  df = gl_error,
  MSerror = cm_error
)
```
