Símbolos útiles para R y Quarto

1 ¿Cómo utilizar esta página?

En RStudio y Quarto utilizamos símbolos cuya ubicación cambia según la distribución del teclado. En esta página podés presionar «Copiar» junto al símbolo y pegarlo en tu código con Ctrl + V (o Cmd + V en Mac).

Atención

Los botones funcionan en el documento HTML renderizado, no en la vista del código fuente .qmd ni en un archivo Word. Para abrir esta página, elegí Render en RStudio. Si el navegador impide copiar automáticamente, seleccioná y copiá el símbolo que aparece en pantalla.

2 Símbolos frecuentes

\Barra invertida (backslash)En R: \n. En LaTeX: \beta.
^Acento circunflejoEn R: 2^3.
`Acento grave (backtick)Markdown: código en línea o bloques.
~Virgulilla (tilde)Fórmulas en R: y ~ x.
|Barra verticalOperador lógico OR: |.
%PorcentajeOperadores de R: %in%.
$Signo pesoEn R: datos$variable.
_Guion bajoEn R: peso_vivo.
#NumeralEn R: comentarios; en Quarto: títulos.
{ }LlavesBloques de código: {r}.
[ ]CorchetesSelección: x[1].
/Barra diagonalDivisión o rutas de archivos.
## Símbolos estadísticos
²Superíndice 2R²; en R: "R\u00B2".
₁Subíndice 1β₁; en R: "\u2081".
βBetaEn R: "\u03B2".
αAlfaEn R: "\u03B1".
μMuEn R: "\u03BC".
σSigmaEn R: "\u03C3".
±Más/menosEn R: "\u00B1".
≤Menor o igualEn R, el operador es <=.
≥Mayor o igualEn R, el operador es >=.
≠Distinto deEn R, el operador es !=.

3 Una distinción importante

Los símbolos ≤, ≥ y ≠ sirven para escribir texto matemático, pero en código de R las comparaciones se escriben con <=, >= y !=.

Del mismo modo, en una fórmula de regresión se escribe y ~ x con la virgulilla real, y no con un código Unicode dentro de una cadena.

3.1 Ejemplo: encabezados de una tabla

flextable(resultados_modelos) |>
  set_header_labels(
    pendiente = "Pendiente (\u03B2\u2081)",
    r_cuadrado = "R\u00B2",
    valor_p_pendiente = "Valor p"
  ) |>
  autofit()

En un párrafo de Quarto, en cambio, podés escribir las fórmulas con LaTeX: $R^2$ o $\beta_1$.

<script>
(function () {
  const aviso = document.getElementById('aviso-copia');
  async function copiar(texto) {
    if (navigator.clipboard && window.isSecureContext) {
      await navigator.clipboard.writeText(texto);
      return;
    }
    const area = document.createElement('textarea');
    area.value = texto;
    area.setAttribute('readonly', '');
    area.style.position = 'fixed';
    area.style.opacity = '0';
    document.body.appendChild(area);
    area.select();
    const ok = document.execCommand('copy');
    area.remove();
    if (!ok) throw new Error('No se pudo copiar automáticamente');
  }
  document.querySelectorAll('.simbolo-btn').forEach(function (boton) {
    boton.addEventListener('click', async function () {
      try {
        await copiar(boton.dataset.symbol);
        aviso.textContent = 'Copiado: ' + boton.dataset.symbol + ' · Pegalo con Ctrl + V.';
      } catch (e) {
        aviso.textContent = 'El navegador impidió copiar automáticamente. Seleccioná el símbolo y copialo manualmente.';
      }
    });
  });
})();

## Una distinción importante

Los símbolos **≤**, **≥** y **≠** sirven para escribir texto matemático, pero en **código de R** las comparaciones se escriben con `<=`, `>=` y `!=`.

Del mismo modo, en una fórmula de regresión se escribe `y ~ x` con la virgulilla real, y **no** con un código Unicode dentro de una cadena.

### Ejemplo: encabezados de una tabla

``` r
flextable(resultados_modelos) |>
  set_header_labels(

    r_cuadrado = "R\u00B2",
    valor_p_pendiente = "Valor p"
  ) |>
  autofit()
```

En un párrafo de Quarto, en cambio, podés escribir las fórmulas con LaTeX: `$R^2$` o `$\beta_1$`.
