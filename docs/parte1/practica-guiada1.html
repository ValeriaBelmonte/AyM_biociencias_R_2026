Práctica guiada 1

1 Próposito

En esta práctica realizaremos nuestro primer trabajo organizado y reproducible en RStudio utilizando Quarto.

Antes de comenzar a escribir código, es importante aprender a organizar correctamente los archivos de trabajo.

2 Paso 1. Crear una carpeta para el proyecto, en la computadora

En el escritorio (o en una ubicación fácil de encontrar), crear una carpeta llamada:

Análisis_agrofood

Esta carpeta contendrá todos los archivos relacionados con el proyecto, organizados en carpetas:

  • datos originales: contiene la base de datos tal como fue recibida. No debe modificarse, para conservar siempre una copia original.
  • datos transformados: contiene las bases de datos que se generen luego de limpiar, seleccionar o crear variables.
  • scripts: contiene los archivos de código utilizados en el análisis, por ejemplo, documentos .qmd o scripts .R.
  • resultados: contiene tablas, resúmenes u otros resultados obtenidos durante el análisis.
  • figuras: contiene los gráficos e imágenes generados en el proyecto.
  • informes: contiene los documentos finales elaborados para comunicar los resultados.
  • prompts (opcional): permite guardar un registro de los prompts utilizados al trabajar con herramientas de inteligencia artificial.

La estructura inicial del proyecto será:

Analisis agrofood/  
├── datos originales/  
├── datos transformados/  
├── figuras/  
├── informes/  
├── prompts/
├── resultados/  
└── scripts/

3 Guardar la base de datos original

Descargar base de datos Agrofood_co2_emission.csv
Agrofood_co2_emission

Utilizando el explorador de archivos de tu computadora, guarda el archivo dentro de la carpeta: datos originales

Analisis agrofood/  
├── datos originales/  
            └── Agrofood_co2_emission.csv
├── datos transformados/  
├── figuras/  
├── informes/  
├── prompts/
├── resultados/  
└── scripts/

4 Paso 2. Crear un proyecto en RStudio

Abrir RStudio y seleccionar:

File → New Project → New Directory → New Project

Existing Directory o New Directory seleccionar la carpeta Analisis_agrofood, como se muestra en las siguientes figuras

Luego:

RStudio creará un archivo con extensión .Rproj, que permitirá trabajar de manera organizada dentro del proyecto.

5 Paso 3. Crear el primer documento Quarto

En RStudio:

File → New File → Quarto Document

Seleccionar:

  • Agregar un título

  • Seleccionar word

  • Crear

Para la escritura, y programación trabajaremos desde Source

6 Paso 4. Escribir en el script dentro de quarto

6.1 Diferenciar texto y código

Quarto permite combinar explicaciones, código y resultados en un mismo documento. Así, el análisis queda ordenado, es reproducible y puede compartirse fácilmente.

Más adelante, en la Parte 6, veremos distintas opciones para personalizar los bloques de código. Para ampliar sobre la escritura de documentos en R Markdown, pueden consultar la guía de R Markdown.

Presionar el botón:

Render

Quarto generará automáticamente un documento donde aparecerán:

el texto escrito, el código y los resultados obtenidos en R.

6.2 Idea central

Quarto permite integrar en un mismo documento:

  • explicaciones, comentarios,

  • código,

  • resultados y gráficos

Esto favorece un trabajo ordenado, reproducible y fácil de compartir. Más adelante, se presentarán las distintas alternativas para configurar los bloques de código

7 Crear y guardar un documento Quarto

Una vez creado el proyecto, abre un nuevo documento Quarto:

  1. Ve a File > New File > Quarto Document.
  2. Escribe un título para el documento.
  3. Haz clic en Create.
  4. Guarda el archivo dentro de la carpeta scripts.

Para guardarlo:

File > Save As…

Selecciona la carpeta:

scripts

y guarda el archivo con el nombre descriptivo, por ejemplo:

practica_co2.qmd

7.1 Bonus de la clase

  1. Para dejar prepardo el Rstudio antes de la clase 2, se instalará y cargará el paquete tidyverse
# Instalación tidyverse
install.packages("tidyverse")
library(tidyverse)

La instalación se realiza una única vez. En cambio, library(tidyverse) debe ejecutarse cada vez que se inicia una nueva sesión de R.

Si la instalación mediante código no funciona o R informa que el paquete no se encuentra, también puede instalarlo desde el menú de RStudio:

tools->Install Packages..->tidyverse
